    #LayerResponsibility

    Verification is not a model reply

    Execution completed, output valid, requirements met, evidence supporting, policy satisfied and approval obtained are separate outcomes.

    Bounded agents

    No agent can raise its own authority, widen its tools or grant permissions to another agent.

    Untrusted inputs

    Files, websites and tool output cannot change the instruction hierarchy.

    Implementation roadmap

    Phases follow the specification. Nothing is described as operational until verified. The existing Command Builder is a prototype and is not a Phase 1 deliverable.
