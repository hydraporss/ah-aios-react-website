Optional: full Flask backend

Worlds, races, governance proposals, sign-in and admin need Python. They are not part of the double-click site.

To run it: Windows — start-flask-backend.bat · Mac/Linux — ./start-flask-backend.command, then open http://127.0.0.1:8080/hub. Needs Python 3 and internet on first run (installs Flask, Flask-Login, Flask-SQLAlchemy). Source is in optional-flask-backend/.

  • The Command Builder is a prototype interface.
  • Being linked together does not verify, canonize or deploy any part. The Flask test suite has not been run.
