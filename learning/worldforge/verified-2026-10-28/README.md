# AH-AIOS WorldForge — Website Prototype

A responsive multi-page website using the supplied WorldForge visual direction: cinematic world imagery, deep navy surfaces, cyan/violet gradients, compact feature cards, and connected navigation.

## Run locally

1. Extract the ZIP archive.
2. Open `index.html` in a modern browser.
3. Use the top navigation, feature cards, ecosystem sections, and footer links to move between pages.

No build step or package installation is required. Google Fonts are optional and require an internet connection; the site falls back to system fonts.

## Pages

- `index.html` — cinematic product homepage
- `doctrine.html` — the three WorldForge laws
- `architecture.html` — the AFTER HUMANITY → WorldForge → AH-AIOS relationship
- `governance.html` — local claim register and seven-gate review checklist
- `constitution.html` — foundational charter
- `explorer.html` — conceptual knowledge model

## Interactivity and limitations

The Governance Lab stores candidate records in this browser's local storage. It is a front-end prototype, not a secure shared database; the readiness checklist is advisory and does not approve canon. The Explorer is a conceptual model rather than a live graph database. Authentication, server persistence, team collaboration, cloud sync, and live AI require backend services that are not included.

The hero and card imagery are crops from the user-provided design reference to carry its visual language through the site.
