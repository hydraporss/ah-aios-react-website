# AH-AIOS Operating Workbench

**AH-AIOS** — AFTER HUMANITY – Artificial Intelligence Operating System
A modular, evolving architecture for knowledge preservation, worldbuilding,
creative execution, AI capability evaluation, and reliable iterative improvement.

## Purpose

This project develops a human-operated workbench and registry for:

- Preserving source provenance, theory identities, and version history
- Keeping CANON, INTERPRETATION, SUGGESTION, and PROCESS distinct
- Reusable skills, workflows, and evaluation criteria
- Recoverable, versioned project state with explicit authorization gates

## Relationships (as established)

- **AION** — metaphysical foundation, the First Nine's ninth position, pure act beyond the numbered Nines
- **AFTER HUMANITY's ATLAS** — the project component for worldbuilding/canon structure
- **AH-AIOS** — the operational architecture: recovery, classification, reconstruction, comparison, testing, integration, authorization

The workbench does not execute tasks autonomously, call an AI, or authorize canon changes.

## Quick start

1. Open `src/ah_aios/__init__.py` to confirm the runtime entry point.
2. Review `docs/GOVERNANCE.md` for the recovery sequence and controlled-integration rules.
3. Review `docs/ARCHITECTURE.md` for the source registry format.
4. Run `node tests/test_registry.js` to verify baseline provenance and classification.

## Directory notes

- `registry/` — machine-readable source records, claims, theory inventory, decisions.
- `src/ah_aios/` — Python package implementing the recovery and verification logic.
- `tests/` — Node-based verification suite for provenance, duplicates, classifications, and authorization.
- `recovered_sources/` — raw files preserved from earlier workspace snapshots; not to be modified.

## Governance

- Every claim retains provenance and verification status.
- Unresolved contradictions are preserved, not silently resolved.
- No imported idea is automatically canonized.
- The recovery sequence is: **RECOVER → CLASSIFY → RECONSTRUCT → COMPARE → TEST → INTEGRATE → AUTHORIZE**.

See `docs/GOVERNANCE.md` for full rules.
