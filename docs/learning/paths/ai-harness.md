# AI Harness Learning Path

## Purpose

Develop the capability to understand, design, evaluate, and safely operate model-, agent-, tool-, and workflow-based systems.

## Modules

1. **Harness foundations** — models, agents, tools, context, instructions, and execution boundaries.
2. **Tools and integrations** — tool contracts, inputs and outputs, permissions, connectors, and error handling.
3. **API integration** — request/response patterns, authentication concepts, schemas, and service boundaries.
4. **Workflow orchestration** — sequencing, state, delegation, retries, observability, and human checkpoints.
5. **Evaluation and reliability** — test design, expected behavior, failure analysis, regression, and reproducibility.
6. **Safe operation** — least privilege, data handling, prompt injection awareness, approval gates, and escalation.

## Applied outcomes

Learner can describe a harness workflow, specify a tool contract, identify authority boundaries, and create a basic evaluation plan for a bounded task.

## Practice

- Design a tool schema with validation and failure cases.
- Map a multi-step workflow and its human approval points.
- Create test cases for success, invalid input, unavailable tools, and unsafe requests.
- Review an execution trace and distinguish observed results from assumptions.

## Assessment evidence

Tool contract, workflow diagram, evaluation cases, and a short safety analysis.

## Boundary

This learning path does not imply live Hermes connectivity, external model calls, or production orchestration in the current WorldForge website. Those capabilities must be verified independently.
