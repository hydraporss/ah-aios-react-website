# AH-AIOS Learning Package

**Package status:** Learning-resource specification and content foundation
**Version:** 0.1.0
**Scope:** Curriculum, learning paths, practice, assessment, portfolio, and content governance.

## Purpose

AH-AIOS Learning is the learning and capability-development environment for understanding, operating, extending, and stewarding the AH-AIOS ecosystem. It connects conceptual learning with practical work, evidence of competency, and responsible system stewardship.

**Learning progression:** Discover → Learn → Experiment → Build → Demonstrate.

## Learning domains

1. **AH-AIOS Core** — system foundations, identity, access, security, governance, policy, audit, evidence, and controlled change.
2. **AI Harness** — models, agents, tools, APIs, orchestration, workflows, evaluation, reliability, and safe operation.
3. **WorldForge** — knowledge modeling, entities, relationships, provenance, canon governance, worldbuilding, and knowledge-graph operations.
4. **Human Stewardship** — cross-cutting capability for judgment, oversight, accountability, and responsible operation. It is not a fourth technical subsystem.
5. **AFTER HUMANITY** — a creative and intellectual knowledge context that can supply learning cases and projects; it is not a separate implementation domain.

## Learning-resource status

This package establishes the content and product specification. It does **not** claim that a complete learning-management application, authentication system, learner analytics service, credential issuer, or AI tutor has been implemented or deployed.

The 82-theory collection is established canon: **68 existing registry theories + 14 synthesized concrete theories**. The 14 are theories, not procedures or placeholders. Their synthesis from the 39 Master Visual Artifacts is complete; separate recovery or inventory of those artifacts is not a prerequisite for this collection.

The package describes learning about AH-AIOS capabilities without upgrading prototype features into production claims. See the WorldForge repository README for current implementation boundaries.

## Use

Treat these documents as the initial versioned learning package. Course content, examples, exercises, and assessment criteria can be expanded while preserving source attribution, review history, and canon status where applicable.
