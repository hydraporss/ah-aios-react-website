# AH-AIOS Learning — Platform Definition

## Product definition

AH-AIOS Learning is a structured learning and capability-development environment for people who design, operate, build, govern, and steward the AH-AIOS ecosystem.

It transforms system knowledge, documented practices, and applied work into progressive learning experiences. Learners move from understanding concepts to practicing workflows, building artifacts, and demonstrating competency through evidence.

## Learning experience

- **Discover:** orientation, system map, terminology, learning goals, and prerequisite awareness.
- **Learn:** structured modules, explanations, examples, references, and guided lessons.
- **Experiment:** exercises, simulations, and bounded practice environments.
- **Build:** practical projects using AH-AIOS Core, AI Harness, and WorldForge concepts.
- **Demonstrate:** assessments, reviewed artifacts, portfolio evidence, and credentials when an authorized credential process exists.

## Product areas

1. Learning dashboard and orientation
2. Learning paths and course catalog
3. Lesson and reference workspace
4. Practice labs and project workspace
5. Assessment and review centre
6. Portfolio and credential records
7. 82-Theory Explorer
8. AI Tutor concept (future capability; no live AI tutor is asserted by this package)
9. Content administration and governance

## Learner roles

- **Learner:** studies content, completes exercises, and submits evidence.
- **Instructor / Reviewer:** provides instruction, evaluates submissions, and records feedback.
- **Content Author:** prepares and maintains learning materials.
- **Learning Administrator:** manages publication, enrollment, learning records, and operational settings.
- **Steward / Governance Authority:** oversees policy, source integrity, protected knowledge, and authorized changes.

A person may hold multiple roles, but the authority attached to each action must be explicit.

## Design principles

- Human-directed learning and accountable review.
- Traceable sources and explicit distinction between fact, interpretation, proposal, and canon.
- Practical competency, not content consumption alone.
- Progressive complexity and visible prerequisites.
- Accessibility, clear language, and reusable learning materials.
- Honest capability labels: specification, prototype, tested, deployed, and production-assured are distinct states.

## Boundary

This document defines the learning product and content model. It is not evidence that the platform UI or backend has been implemented.
