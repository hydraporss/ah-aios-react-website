# Assessment, Portfolio, and Credentials

## Assessment model

Assessment should evaluate demonstrated capability through artifacts and explanation, not lesson completion alone.

### Assessment methods

- Knowledge checks for terminology and conceptual understanding.
- Scenario analysis for judgment and application.
- Practical labs for operational capability.
- Projects for integrated engineering capability.
- Oral or written defense for explanation and reasoning.
- Review of portfolio evidence for sustained competency.

## Rubric dimensions

1. **Accuracy:** correctness of concepts and execution.
2. **Traceability:** sources, inputs, and decisions are identifiable.
3. **Completeness:** required elements and edge cases are addressed.
4. **Reasoning:** assumptions, alternatives, and uncertainty are made explicit.
5. **Verification:** outcomes are tested against stated criteria.
6. **Stewardship:** protected information, authority boundaries, and change discipline are respected.

Assessment levels should map to the curriculum's L0–L4 competency levels. Rubric criteria must be published before assessment.

## Portfolio record

A portfolio item should contain:

- Learner and artifact identifiers.
- Competency and learning objective.
- Artifact title, description, and version.
- Submission date and source references.
- Test / verification evidence.
- Reviewer identity and rationale, when reviewed.
- Outcome, feedback, and resubmission history.

## Credentials

Credentials may be issued only through an explicitly authorized process with defined issuer authority, identity verification, assessment requirements, record retention, and revocation/correction rules.

This package defines credential concepts only. It does not implement or issue credentials.
