# WorldForge Learning Path

## Purpose

Develop the ability to model connected knowledge and worlds while preserving provenance, reviewability, canon integrity, and continuity.

## Modules

1. <b>Knowledge-model foundations</b> — entities, attributes, identifiers, relationships, and controlled vocabularies.
2. <b>World modeling</b> — worlds, nations, characters, factions, locations, events, timelines, and dependencies.
3. <b>Sources and claims</b> — source registration, claim formulation, attribution, and uncertainty.
4. <b>Evidence and provenance</b> — evidence records, assessments, links, version history, and traceability.
5. <b>Canon governance</b> — lifecycle states, reviewer rationale, protected records, change proposals, conflict, supersession, and rollback.
6. <b>Knowledge graph operations</b> — relationship validation, traversal, connection views, search, and export/import.
7. <b>World continuity</b> — temporal consistency, entity identity, causal relationships, and narrative continuity.
8. <b>Trust and risk</b> — source reliability, conflicting claims, governance boundaries, and operational risk.

## Applied outcomes

Learner can construct a small world model, connect entities with valid relationships, attach source and evidence records, and explain a canon change with traceable rationale.

## Practice

- Model a bounded fictional setting.
- Add entities and typed relationships.
- Register sources and formulate claims.
- Attach evidence with explicit assessment labels.
- Submit a change proposal and document its review path.
- Inspect lineage and export a workspace snapshot.

## Assessment evidence

A small world workspace, relationship validation results, provenance trail, and canon-change case study.

## Boundary

The repository currently describes a browser-local WorldForge prototype and a separate Django Server Governance foundation. Browser-local records are not synchronized with the server API; end-to-end browser acceptance and production deployment remain separate verification requirements.
